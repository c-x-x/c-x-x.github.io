## AI漫剧制作SOP

```mermaid
flowchart LR
    A["需求对接<br/>（商务）"] --> B["剧本拆解<br/>（导演）"]
    B --> C["人员分工<br/>（制片）"]

    C --> D["设定制作<br/>（主美、生图师）"]
    C --> E["分镜拆分<br/>（生图师）"]
    C --> F["声音素材筹备<br/>（制片、后期）"]

    E --> G["静帧生成<br/>（生图师）"]
    G --> H["静帧审核定稿<br/>（主美、导演）"]

    H --> I["视频生成<br/>（生图师）"]
    I --> J["视频审核<br/>（主美一审）"]
    J --> K["视频审核<br/>（导演终审）"]

    K --> L["影片合成<br/>（后期）"]
    L --> M["成品审核<br/>（导演终审）"]
    M --> N["成品交付<br/>（商务）"]
```

阶段说明

```mermaid
flowchart LR
    A["剧本<br/>创意与结构化"]
    B["分镜<br/>可视化设计"]
    C["生图<br/>静帧画面生成"]
    D["视频<br/>动态化处理"]
    E["合成<br/>声画定稿"]

    A --> B --> C --> D --> E

    classDef step fill:#F4F3FF,stroke:#9C83D9,stroke-width:1.5px,color:#333;
    class A,B,C,D,E step;
```

| 阶段 | 核心输入 | 核心产出 |
| --- | --- | --- |
| 1. 剧本 | 小说 / IP | 结构化分镜脚本：包含场景、景别、人物动作 / 表情、关键台词 |
| 2. 分镜 | 分镜脚本 | 视觉化分镜稿：精准的提示词，指导画面生成 |
| 3. 生图 | 分镜提示词 | 风格统一的静帧图片：解决角色一致性是关键 |
| 4. 视频 | 静帧图片 | 动态视频片段：为静态图添加运镜、动态 |
| 5. 合成 | 视频片段、音频素材 | 成品漫剧：完成剪辑、配音、音效、字幕、调色 |
